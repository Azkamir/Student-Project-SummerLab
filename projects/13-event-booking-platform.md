## 13  Event Booking Platform

## Overview

Develop a platform where users can discover events, reserve tickets, and manage bookings while organizers manage their events.

## Core Features

* Event creation
* Event discovery
* Search and filtering
* Ticket booking
* Booking history
* Organizer dashboard
* Event management
* Reviews

## Possible Extensions

* Personalized event recommendations
* QR-code tickets
* Attendance analytics
* Dynamic pricing
* Fraud detection

## Suggested Difficulty

Intermediate
